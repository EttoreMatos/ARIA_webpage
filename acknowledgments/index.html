Agradecimentos

A ARIA existe graças a uma pilha enorme de código aberto, APIs e ferramentas. Esta página lista as linguagens, bibliotecas e serviços usados no bot, na API e no site.

Linguagens

O coração da ARIA e a cola entre Discord, IA, voz, pagamentos e a página.

Python HTML CSS JavaScript SQL Shell

Bot Discord — núcleo

  • discord.pyFramework do bot, slash commands, embeds, eventos e voice client.
  • python-dotenvCarrega variáveis de ambiente e segredos de configuração.
  • asyncpgCliente assíncrono PostgreSQL para histórico, XP, planos e configs.
  • aiohttpHTTP assíncrono para busca web, mídia e integrações externas.
  • pytz / zoneinfoFusos horários em lembretes, logs e agendamentos.
  • json-repairRepara JSON inválido devolvido por modelos de IA.

Bot — voz e áudio

  • discord.py[voice]Suporte de voz nativo do discord.py.
  • discord-ext-voice-recvRecebe áudio dos membros na call para STT.
  • daveySuporte DAVE / encriptação moderna de voz Discord.
  • pydubManipulação e conversão de áudio.
  • soundfileLeitura/escrita de ficheiros de áudio.
  • numpyProcessamento numérico de buffers de áudio.
  • elevenlabsTTS premium da ElevenLabs.
  • edge-ttsTTS gratuito via Edge como fallback.

Bot — IA, mídia e web

  • mistralaiSDK oficial Mistral para chat, visão e ferramentas.
  • easy-pilGeração de imagens (cartões, mini-jogos, overlays).
  • youtube-transcript-apiTranscrições de vídeos do YouTube.
  • yt-dlpMetadados e extração de informação de vídeos.
  • TavilyAPI de busca web (via HTTP, sem pacote Python dedicado).

API de assinaturas (aria-api)

  • fastapiAPI HTTP para OAuth Discord, checkout e webhooks.
  • uvicornServidor ASGI de produção.
  • pydanticValidação de payloads e modelos de dados.
  • httpxCliente HTTP para Discord OAuth e serviços externos.
  • stripeCheckout, assinaturas e webhooks de pagamento.
  • itsdangerousTokens assinados no fluxo de autenticação/handoff.
  • asyncpgPersistência dos estados Premium / Server.
  • python-dotenvConfiguração da API por ambiente.

Site e frontend

  • HTML5Estrutura das páginas públicas.
  • CSS3Layout, tema visual e responsividade.
  • JavaScriptNavegação, auth Discord, checkout Stripe e animações.
  • Google FontsCaveat, Dancing Script, Sora e IBM Plex Mono.

Infraestrutura e serviços

  • PostgreSQLBase de dados principal da ARIA.
  • DiscordPlataforma onde a ARIA vive e fala.
  • StripePagamentos Aria Premium e Aria Server.
  • RenderHosting do site, da API e do bot.
  • Mistral AIModelos de linguagem e multimodal.
  • ElevenLabsVoz sintética premium.
  • TavilyBusca web para respostas com fontes.
  • FFmpegBackend de conversão de áudio usado pelo pydub/voz.

Testes e qualidade

  • pytestSuíte de testes do bot e da API.
  • pytest-asyncioSuporte a testes assíncronos.

Módulos internos da ARIA

Além das libs externas, o projeto organiza a lógica nestes pacotes:

  • aria/Núcleo do bot: eventos, IA, STT/TTS, DB, personalidade, DM relay.
  • cogs/Comandos Discord (geral, moderação, utilidades, admin, diversão).
  • services/Planos Premium, embeds, filas de IA, helpers e bancos locais.
  • aria-api/Backend FastAPI de login Discord, billing e webhooks Stripe.
  • site/Página pública, planos, legal e estes agradecimentos.
  • prompts/System prompts e instruções de comportamento da ARIA.
